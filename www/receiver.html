Your browser downloads a .rtcm3 file that keeps growing until the time is up or you press Stop and finish file. Keep this computer awake and on the same WiFi until then — if the connection drops the browser may discard the unfinished download. The file contains exactly what the casters receive. For precise coordinates convert it to RINEX with RTKLIB RTKCONV and submit to AUSPOS (1 h minimum, 2 h recommended, 6 h or more is better).

Apply base setup (UM980)
Decimal degrees (south is negative) and ellipsoidal height in metres (AUSPOS “Ellipsoidal height”, not the AHD / sea-level height). The page converts this to ECEF X/Y/Z, so the receiver can't mistake which height it is. Use the current announced position Enter plain decimal numbers, e.g. -38.30942616 146.39974564 96.447

Each command must be answered with OK by the receiver. If one fails or gets no answer, the sequence stops before saving, so the receiver's saved settings are untouched (power-cycle it to go back to them).
